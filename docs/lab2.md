- On ne peut plus pousser direct sur main : le ruleset impose de passer par une PR, donc la CI tourne forcément avant que quoi que ce soit arrive sur main. Sur ma PR #1, GitHub a refusé le merge tant que les checks étaient rouges.
- Les deux checks kraken / lint-test et kraken / build-push sont obligatoires. Le premier lance ruff et pytest, le second build l'image, donc un test cassé ou un Dockerfile qui ne build plus bloquent le merge. Je l'ai testé en mettant une mauvaise valeur dans un test : lint-test est passé au rouge, build-push a été sauté et le bouton Merge est resté grisé jusqu'à ma correction.
- L'image n'est poussée sur GHCR (avec le SHA du commit comme tag) qu'après un merge sur main. Sur une PR elle est juste construite pour vérifier que ça marche, donc rien qui n'a pas passé les checks ne se retrouve dans le registre.
